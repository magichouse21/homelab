# Homelab

Personal infrastructure and security projects, run on VMs and a Raspberry Pi.

## Projects

- **[Wazuh SIEM Lab](./wazuh-siem)** — deployed a SIEM to detect brute-force
  login attempts across multiple OS agents
- **[OpenWrt Router](./openwrt-router)** — built a segmented home network
  with a default-deny firewall on a Raspberry Pi
- **[Userspace TCP/IP Stack](./tcp-ip-stack)** — implemented Ethernet/ARP
  parsing in C over a Linux TAP device
